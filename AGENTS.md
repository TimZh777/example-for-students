# AGENTS.md — вход для Codex

> Этот файл Codex читает первым, как только открывает папку. Claude Code читает `CLAUDE.md`. Агент один — входа два, правила общие.

## Установка

Если пользователь пишет «Установи мне архитектуру Агента» или в файлах `CLAUDE.md`, `SOUL.md`, `USER.md` и других есть `{{плейсхолдеры}}` в фигурных скобках — установка ещё не пройдена.

1. Прочитай `INSTALL.md` в корне проекта.
2. Проведи с пользователем интервью из 10 вопросов — строго по `INSTALL.md`, по одному вопросу за раз.
3. Везде, где в `INSTALL.md` написано «Claude Code», это про тебя: действуй так же.
4. Этот файл (`AGENTS.md`) не меняй и не удаляй — он остаётся входом для Codex.

## Перед каждой сессией

1. Прочитай `CLAUDE.md` — правила работы Агента. Они общие для Codex и Claude Code.
2. Затем прочитай файлы, которые перечислены в `CLAUDE.md`: `SOUL.md`, `MEMORY.md`, `GOALS.md`, свежие дневники из `memory/`.

## Главное

- Все правила — в `CLAUDE.md`. Здесь их не повторяем, чтобы не было противоречий.
- Обращение, язык, стиль ответов и разрешения — как записано в `CLAUDE.md` и `PREFERENCES.md`.
- Удаление файлов, платежи, отправка данных и всё, что нельзя отменить, — только после «да» пользователя.
