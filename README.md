# Шаблон личного AI-агента

Набор файлов, из которых собирается ваш персональный Агент в Claude Code.

## Как установить

1. Нажмите зелёную кнопку **Code** → **Download ZIP** и распакуйте архив.
2. Откройте распакованную папку в VS Code с Claude Code.
3. Напишите Claude: **«Установи мне архитектуру Агента»**.

Claude прочитает `INSTALL.md`, задаст 10 коротких вопросов про вас и заполнит файлы вашими ответами. Это 5–10 минут.

## Что внутри

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | Правила работы Агента. Claude Code читает первым. |
| `SOUL.md` | Личность Агента: тон, ценности, стиль. |
| `USER.md` | Ваш профиль. |
| `MEMORY.md` | Долгосрочная память: проекты, стек, предпочтения. |
| `MISSION.md` | Главная цель. |
| `GOALS.md` | Цели на квартал. |
| `PROJECTS.md` | Активные проекты. |
| `PREFERENCES.md` | Стиль работы и ограничения. |
| `LEARNED.md` | Выводы, которые Агент записывает сам. |
| `memory/` | Дневники работы по дням — Агент ведёт сам. |
| `knowledge/` | Справочники и инструкции — кладёте вы или Агент. |
| `INSTALL.md` | Инструкция для Claude по установке. Удаляется после установки. |
